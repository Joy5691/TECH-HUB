# 📖 Overview

TECH HUB is a modern, fully responsive electronics e-commerce website developed using HTML5, CSS3, JavaScript, and Firebase.

The project simulates a real online shopping platform where users can browse products, compare specifications, manage their shopping cart and wishlist, create accounts, and securely place orders.

The website also contains a complete admin dashboard for managing products, categories, users, orders, and analytics.

This project demonstrates front-end web development, responsive UI design, Firebase integration, authentication, and client-side e-commerce functionality.
